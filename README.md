# Raft in a page

The page served at https://raft.umbertogotti.dev: a Raft cluster simulated in
the browser, the protocol compiled to WebAssembly, every node of a cluster
running in one page, to watch and to play with.

This repository holds the page as built and nothing of its source. Each
commit publishes one build and names the commit it was built at; the page
names its build too, and so does a run written out from it.
